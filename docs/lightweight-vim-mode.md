# 轻量 Vim 模式

轻量 Vim 模式默认关闭，可在设置界面的“光标 → Vim 模式”中启用，也可在 `settings.json` 中设置：

```json
{
  "vim_mode": true
}
```

启用后，普通文件编辑器以普通模式启动。按 `i`、`a`、`I`、`A`、`o` 或 `O` 开始输入，按 `Esc` 返回普通模式。设置变更会应用到已打开的编辑器。

## 模式与移动

| 操作 | 按键 |
| --- | --- |
| 左、下、上、右移动 | `h`、`j`、`k`、`l` |
| Visual 模式移动并扩展选区 | `h`、`j`、`k`、`l` 或方向键 |
| 按单词移动 | `w`、`b`、`e`、`W`、`B`、`E`、`ge` |
| 行内移动 | `0`、`^`、`$` |
| 文件开头、结尾 | `gg`、`G`；`5gg`、`5G` 跳到指定行 |
| 半屏滚动 | `Ctrl-d`、`Ctrl-u` |
| 整屏移动 | `Ctrl-f`、`Ctrl-b`（Visual 模式下扩展选区） |
| 调整光标行在屏幕的位置 | `zz` 居中，`zt` 置顶，`zb` 置底 |
| 移至段落边界 | `{`、`}` |
| 字符查找 | `f{字符}`、`F{字符}`、`t{字符}`、`T{字符}` |
| 重复上次字符查找 | `;` 同向，`,` 反向 |
| 匹配括号跳转 | `%` |

字符查找限于当前行。`f/F` 跳到目标字符，`t/T` 停在目标字符旁。等待输入查找字符时，按 `Esc` 取消。

## 编辑

| 操作 | 按键 |
| --- | --- |
| 插入 | `i`、`a`、`I`、`A` |
| 在上方或下方新建行 | `O`、`o` |
| 删除字符、行 | `x`、`dd` |
| 复制行 | `yy` |
| 删除到行尾 | `D` |
| 修改到行尾、整行 | `C`、`cc` |
| 修改整行 | `S` |
| 替换字符 | `r` 后输入一个字符 |
| 替换字符并进入插入 | `s` |
| 转为小写、大写 | `gu{移动}`、`gU{移动}`，例如 `guw`、`gUiw` |
| 切换大小写 | `~`（当前字符），或 Visual 选择后按 `~` |
| 切换注释 | `gcc` 当前行；`gc{移动}` 或 `gc{文本对象}`，例如 `gcw`、`gcip` |
| 粘贴到光标后或前 | `p`、`P` |
| 合并行 | `J` |
| 增加、减少缩进 | `>>`、`<<` |
| 按语言自动缩进 | `==` |
| 撤销、重做 | `u`、`Ctrl-r` |
| 重复上次修改 | `.` |

## 操作符、次数与选择

`d`、`c`、`y` 可以与移动、文本对象、字符查找和 `%` 组合。例如：

- `d2w` 删除两个单词；`d2p` 删除两个段落。
- `ciw` 修改当前单词；`caw` 修改当前单词并包含周围空白。
- `di"` 删除引号内的内容；`da(` 删除括号及括号内内容。
- `dgg` 删除到文件开头；`dG` 删除到文件结尾；`d5G` 删除到第 5 行。
- `dt,` 删除到逗号前；`df)` 删除至右括号并包含它；`d%` 删除到匹配括号。
- `3J` 合并三行；`3>>` 缩进三行。
- `v` 进入字符选择，`V` 进入行选择；`o` 切换选区活动端。选择后可按 `y` 复制、`d`/`x` 删除、`c` 修改选区，或使用 `>`、`<`、`=` 处理所选行。`viw`、`vaw`、`vi(`、`va{`、`vip` 等可将当前光标所在文本对象选入 Visual 模式。
- `3.` 将上次修改重复三次。`u` 撤销重复操作。

`*`、`#` 从光标所在单词向后或向前查找完整单词，并高亮当前缓冲区中的匹配；`n`、`N` 按上次查找方向或反方向继续查找。查找区分大小写。

计数可以放在操作符前或移动前，例如 `2d3w` 表示删除六个单词。`3.` 会设置重复次数，后续单独按 `.` 会沿用该次数。

## 搜索

`/` 打开当前文件搜索；`n`、`N` 跳转到下一个或上一个匹配。

这是面向日常编辑的有限模式，不支持宏、寄存器、块选择、完整 `:` 命令行、Vim 脚本或完整 Vim 配置兼容。Visual 选区修改暂不支持用 `.` 重复。括号匹配优先使用语言语法信息；没有语法信息时使用文本匹配。终端的 Vi 模式与编辑器设置相互独立。

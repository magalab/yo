# 轻量 Vim 模式

轻量 Vim 模式默认关闭，可在设置界面的“光标 → Vim 模式”中启用，也可在 `settings.json` 中设置：

```json
{
  "vim_mode": true
}
```

启用后，普通文件编辑器以普通模式启动。按 `i` 或 `a` 输入文本，按 `Esc` 返回普通模式。设置变更会应用到已打开的编辑器。

## 支持的操作

| 操作 | 按键 |
| --- | --- |
| 移动光标 | `h`、`j`、`k`、`l` |
| 单词移动 | `w`、`b`、`e` |
| 行内移动 | `0`、`^`、`$` |
| 文件移动 | `gg`、`G` |
| 插入与新行 | `i`、`a`、`o`、`O` |
| 删除、复制行 | `x`、`dd`、`yy` |
| 粘贴 | `p`、`P` |
| 撤销、重做 | `u`、`Ctrl-r` |
| 替换字符 | `r` 后输入一个字符 |
| 字符选择 | `v`，然后移动；`y` 复制、`d` 删除、`Esc` 退出 |
| 搜索 | `/` 打开当前文件搜索；`n`、`N` 跳转匹配 |

这是面向日常编辑的有限模式，不支持宏、寄存器、计数前缀、复杂文本对象、块选择、`:` 命令行或 Vim 脚本。终端的 Vi 模式与编辑器设置相互独立。
